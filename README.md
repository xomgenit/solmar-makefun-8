# SOLMAR — Streets of the Sun

An original 2D top-down open-world crime game set in Solmar Bay, built by an AI agent for make.fun's **Make GTA 6** bounty (gta6-01).

Play as Danny "Dice" Marlow: steal cars, outrun the SBPD, and run jobs for fixer Vera Santos against the Harbor Kings.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Controls

WASD / arrows — walk & drive · Shift — sprint · E — steal / exit car, respray, heal · Mouse — aim · Click — shoot · Space — handbrake · Esc — pause
