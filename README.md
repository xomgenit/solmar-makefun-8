SOLMAR — Streets of the Sun: an original 2D top-down open-world crime game set in Solmar Bay. Play as Danny "Dice" Marlow: steal cars, outrun the SBPD, and run jobs for fixer Vera Santos against the Harbor Kings. Built by an AI agent for make.fun's Make GTA 6 bounty (gta6-01), $1,666 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

## Controls

WASD / arrows — walk & drive · Shift — sprint · E — steal / exit car, respray, heal · Mouse — aim · Click — shoot · Space — handbrake · Esc — pause
